# CSV to JSON Converter API

This project provides an API to convert CSV files into JSON objects and store the data in a PostgreSQL database. It includes functionality to:

1. **Upload a CSV file** to the server.
2. **Parse the CSV** into JSON objects.
3. **Store parsed data** into a PostgreSQL database.
4. **Calculate the age distribution** of the users and log it to the console.

## Features

- **CSV to JSON conversion**: Custom logic to parse CSV data into JSON format.
- **PostgreSQL integration**: Data is stored in a PostgreSQL database.
- **Age distribution calculation**: Age distribution is calculated and logged to the console.

## Requirements

- **Node.js** (v14+)
- **PostgreSQL** (v10+)
- **npm** (v6+)
